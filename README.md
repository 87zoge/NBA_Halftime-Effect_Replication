# Can losing lead to winning? Revisiting the Halftime Effect in Basketball

Replication package for my seminar thesis (Seminar on Quantitative Methods in Sports, University of Zurich, Fall 2026).

Berger and Pope (2011) find that NBA teams trailing by one point at halftime win more often than expected. This paper re-estimates their regression discontinuity design on every regular-season NBA game from 1993/94 to 2024/25 and asks whether the effect survives into the three-point era.

- In Berger and Pope's sample period (1993/94–2008/09), teams just behind at halftime are 4.8 percentage points more likely to win (SE 1.8).
- From 2014/15 on, the effect is gone (−1.1 pp, SE 2.2), and the drop is significant (−5.8 pp, p = .04).
- The effect also disappears in the three seasons with a shortened three-point line (1994/95–1996/97), which suggests that three-point shooting plays a role.

## Running the code

Tested with Python 3.14.7 and the package versions in `requirements.txt`.

```bash
pip install -r requirements.txt
python analysis.py
```

`analysis.py` reads `data/nba_games.csv`, writes every table and figure to `output/` and takes about 20 seconds.

The dataset is included, so you don't need to download it again. To rebuild it from the source, run `python get_data.py`. It queries ESPN's public scoreboard API once per date (about 8,800 requests, a few hours) and caches the responses in `data/raw_espn/`. ESPN's API is undocumented and may change, so a fresh download may not match the included file exactly.

## Data

The source is ESPN's public scoreboard API (`site.api.espn.com/apis/site/v2/sports/basketball/nba/scoreboard`). Each game includes the teams, quarter-by-quarter scores, the final score, the season type, whether it was played at a neutral site, and both teams' field-goal and three-point attempts.

`data/nba_games.csv` is derived from this API and is shared only so that the results can be replicated for academic purposes. This project is not affiliated with or endorsed by ESPN.

The MIT license applies to the code. data/nba_games.csv is derived from ESPN’s API and is not covered by it.

`get_data.py` drops games that were not completed, All-Star and exhibition games, malformed entries, and games whose period scores do not add up to the final score. Overtime games are kept. `analysis.py` then keeps regular-season games, excluding neutral-site games and games tied at halftime. That leaves 36,230 games. Shot data are missing for about 3% of these games, so the three-point shares use the games that have them.

Seasons are labelled by the year they end (`season` = 2015 is 2014/15).
